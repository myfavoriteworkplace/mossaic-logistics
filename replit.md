# AeroPulse Logistics

## Run the website

- Replit preview workflow: `npm run dev -- --host 0.0.0.0 --port 5000 --ignore-lock`
- Production build: `npm run build`
- Local development: `npm run dev`

The landing page is a static Astro site. Shipment IDs, routes, and rate estimates use local illustrative data; no carrier API, live tracking, shipment booking, or quote submission is connected. Sample tracking IDs are displayed beside the lookup form.
